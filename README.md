# 起始页 · simple_web

一个自用的浏览器起始页：一行搜索框，下方是天气与 LoL 赛程两张卡片。纯静态、无构建、无第三方依赖，双击 `index.html` 即可使用。

---

## 目录结构

```
simple_web/
├── index.html      # 页面骨架：搜索框、天气卡片、日历卡片、设置抽屉、主题面板
├── style.css       # 全部样式：主题变量、布局、组件、动效、响应式
├── app.js          # 全部逻辑：搜索、主题、设置、天气、赛程、日历
├── data/
│   ├── weather.js  # 天气预置数据：接口清单 + 城市清单
│   └── lol.js      # 赛事接口配置：API Key、语言、排除项
└── README.md       # 本文档
```

`data/` 下的文件通过 `<script>` 载入，用 `file://` 直接打开也能读到；改完刷新页面即生效。

---

## 功能

**搜索**

- 输入网址直接跳转（自动补 `https://`），输入关键词交给当前搜索引擎
- 四个引擎可切换：必应 / 百度 / Google / DuckDuckGo，选择会记住
- `/` 或 `Ctrl + K` 聚焦搜索框，`Esc` 关闭浮层

**天气卡片**

- 显示城市、当前温度、天气描述、风力 / 湿度 / 气压 / 空气质量
- 下方折线图为未来几天的最高温 / 最低温，列数按接口返回的天数自动适配
- 数据缓存 15 分钟，右上角可手动刷新

**日历 / 赛程卡片**

- 单周日期条，支持上一周 / 下一周 / 回到今天，有比赛的日期下方带红点
- 当天比赛单行展示：时间 · 赛段与赛制 · 队徽 + 队名 + 比分
- 最多显示 3 行，超出部分内部滚动；标题旁的主题色角标显示当天场数
- 赛事数据来自 Riot 官方赛事接口，缓存优先、后台刷新，断网时保留上次数据

**主题与设置**

- 10 套主题色，默认每次打开随机一套；手动选色后固定，面板末尾的虚线圈可切回随机
- 浅色 / 深色模式一键切换
- 设置抽屉（右上角齿轮）：切换赛事、天气接口，查看当前城市并按需新增
- 所有配置存在浏览器 `localStorage`，换浏览器或清缓存会重置

## 天气数据来源

天气数据来自第三方免费接口，提供方：<https://api.hgovo.cn/index.php>

- 接口：`https://api.hgovo.cn/API/zgtq`
- 参数：`city`（城市名，中文）、`days`（可选，预报天数，默认 5）
- 返回：`{ code: 200, data: { location, current, forecast[] } }`，`data/weather.js` 里配置的就是这个地址
- 该接口允许跨域，`file://` 打开也能直接请求；接口本身不缓存，本项目在浏览器里缓存 15 分钟

接口可用性、限流与字段结构均不受本项目控制，不可用时天气卡片会显示错误态并提供重试。若要换源，在设置抽屉里新增接口，或修改 `data/weather.js` 的 `apis`，接口需满足 `GET {url}?city=城市名` 并返回同样结构。
